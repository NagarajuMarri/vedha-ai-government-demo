# Prompt Versions

## Mathematics lesson prompt 1.1.0

Version 1.1.0 strengthens Sprint 4A.1 educational quality for elementary
Mathematics lessons, especially Pure Telugu output. It adds natural Telugu and
approved terminology guidance, keeps basic fraction explanations within the
learner's requested scope, and states numerator/denominator positions clearly.

The deterministic reviewer complements the prompt with safe checks for
unexpected scripts or encoding corruption, known incorrect terminology,
excessive elementary scope, and reversed or missing numerator/denominator
positions. These checks do not make a second AI request and do not replace
human review of grammar or full semantic accuracy.
